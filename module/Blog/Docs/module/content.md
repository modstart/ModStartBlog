## 模块介绍

「个人博客」提供了一个简约的模块系统

```mind
功能特性
    图文博客
    博客分类
    博客标签
    博客归档
    博客评论
    友情链接
    留言本
    关于博主
    暗黑/白天主题
    批量导入
```





## 模块入口

- `/blog` 博客首页
- `/blog/about` 关于博主
- `/blog/message` 留言本
- `/blog/tags` 标签云
- `/blog/archive` 文章归档
- `/blogs` 博客列表
- `/blog/{id}` 文章详情
